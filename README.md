# Milo CPU

A custom 32-bit CPU architecture designed from scratch.

License: MIT

## Features

- 32-bit architecture
- 16 General Purpose Registers
- Three internal buses
- Hardwired Control Unit
- Custom ISA
- Custom Assembler
- Logisim Evolution implementation
